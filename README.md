# SoftEvo — 進化観察ラボ

自分で設計した生き物が、ニューラルネットワークの脳を進化させて歩き出すまでを観察する、**ドット絵のレトロなゲーム**です。
公開ページ: https://eieimuse-ctrl.github.io/softevo/

- SoftEvo 8 から すもう・つなひき を外し、かけっこだけに絞った版 (旧 softevo9/) を、見た目ごとドット絵に作り替えたもの
- 歩行の物理と進化のしくみは SoftEvo 8 と1ビットも変わっていません (同じ体・同じ脳なら同じ結果になります)
- ビルド不要・外部依存なし (ES Modules + Web Worker + Canvas)、PWA 対応
- 旧URL `softevo9/` はここへ転送します。保存データ・オンラインのデータ名は以前と同じ `softevo9` のままなので、引き継がれます
- **英語 / 日本語** — デフォルトは英語。ホームの「⚙ Settings / 設定」で切り替え (選んだ言語は保存される)。リンクで指定するときは `?lang=en` / `?lang=ja`

## 🎬 リール (Instagram の縦動画)

`reel/` に、生き物が歩けるようになるまでを縦動画 (1080×1920 / 30fps・英語のみ) にする枠組みがあります。
エピソードの自動生成 → 再生ページで確認 → PNG 連番に書き出し (動画への変換は別の場所で)。くわしくは [reel/README.md](reel/README.md)。

## ドット絵のしくみ

- **パレット (36色)**: 夜の研究所の紺 9段 + 地面のティール + 金・橙(興奮性)・青(抑制性)・桃・紫・赤・若草 の明暗 (`ui.js` の `PAL`)。
  筋肉は 8 色相 × 3 段 (伸びている=暗 / ふつう=中 / 縮んでいる=明) で、脳の出力ニューロンと同じ色
- **キャンバス**: すべて `fitCanvas()` を通る。描画は 1ドット = 2〜3 CSS px の低解像度の裏キャンバスに行い、
  描き終わりに (同じタスクの最後に) 全画素をパレットへ丸めてから、ぼかさずに拡大して表に出す。
  呼び出し側は今まで通り CSS px で描けばよい
- **文字**: キャンバスの文字だけは表の高解像度キャンバスに DotGothic16 で描き直す (小さな日本語も読めるように)。矩形のクリップも引き継ぐ
- **ドット単位の部品**: 節点・目・ニューロンはきっちりしたドットの円 (`pixelDisc`)、地面は列ごとに高さを測って表面2段 + 土の模様、
  空は帯 + 市松の境目、星と2層の山は視差つき
- 処理の重さはドット化の前と同じ (CPU 1/4 の条件で比較)

## 🎲 おまかせ

ホームの「おまかせで始める」と、設計画面の「🎲 おまかせ」は、押すたびにちがう体をつくります。
背骨 (2〜5節) の高さ・間隔・反り、腹の補強、脚 (0〜5本・1〜2関節)、頭、しっぽを乱数で決め、関節をまたぐように筋肉を張ります。
座標は 5cm 刻みなので、そのまま手で直せます (300体の試験で、すべて設計として正しく、ランダムな脳で動かしても壊れない)。

## 何が大事だと考えたか

| ユーザーが本当に欲しいもの | SoftEvo での答え |
|---|---|
| **一世代ずつじっくり見たい／待たずに進めたい** | 既定は「▶ 観察」: 再生1回につき1世代ずつ進化。「⏩ 高速」にすると Web Worker で全力実行（デスクトップで毎分数百世代） |
| **でも一匹一匹をちゃんと見たい** | 物理が完全に決定論的なので、Worker が評価した個体を画面上で**寸分違わず再現**できる。「劇場」は各世代のチャンピオンを再生し、同世代のライバルをゴーストで重ねる |
| **脳と体のつながりを理解したい** | 入力ニューロンに「筋3 伸び」「点2 接地」など意味のある名前。筋肉と出力ニューロンを同じ色で統一。ニューロンをタップ→体の部位が光る、体の筋肉をタップ→対応ニューロンが選ばれる |
| **脳が「何をしているか」を確かめたい** | 🔪 **ノックアウト（脳の手術）**: ニューロンを止めると、走っている最中の個体の動きが変わる。因果関係を自分の手で実験できる |
| **進化で何が変わったのか知りたい** | 脳の **変異モード**: 親からどのシナプスが変わったかをピンク/紫で表示 |
| **進化の物語を感じたい** | 「はじめて前進」「5m の壁を突破」「大躍進」「新しい動き方を発見」「新系統誕生」「系統が集団を制覇」「停滞→変異強化」「環境変化」を自動で検出して **物語（ジャーナル）** に記録。タップでその世代へ |
| **成長をひと目で実感したい** | **パレード**: 第0世代・節目の世代・最新世代をレーンに並べて同時に走らせる |
| **動きのリズムを見たい** | **歩容図**: 筋肉の収縮と足の接地を楽譜のように表示。歩き方が確立すると模様が規則的になる |
| **集団の中の「血筋」を見たい** | 記録を大きく更新した個体が新系統の祖になり、子孫が系統を受け継ぐ。**ミュラー図**で系統の盛衰が見える |
| **環境への適応を見たい** | 途中で地形(平地/丘陵/でこぼこ/階段)・目標(距離/省エネ/跳躍)・重力・摩擦を変更可能。推移グラフに境界線が入る |
| **作るのは簡単に** | タップでノード、ドラッグで骨/筋肉。空白までドラッグすると新ノードごと伸びる。左右対称モード、元に戻す、プリセット、ランダムな脳での試運転 |
| **失くしたくない** | 25世代ごと・画面を離れる時に自動保存。JSON 書き出し/読み込み |

## 🏃 かけっこ

育てた生物 (好きな世代)・道場の師範・オンラインの生物を、最大6体まで横一列に並べて走らせます。

- **走る場所**: 「共通の地形」(平地 / 丘陵 / でこぼこ / 階段) か「それぞれの故郷」(各自が進化した地形・重力・摩擦)
- 各レーンのカメラが自分の生物を追い、ほかの生物はゴーストで重なる。上の細い地図で全体の位置関係が見える
- 過去の自分 (前の世代) とも競えるので、進化の成果をそのまま比べられる
- 物理は決定論的なので、同じ組み合わせは何度見ても同じ結果

## 🌐 オンライン

生物 (体 + 脳) を公開すると、だれでもその生物と一緒に走れます。

- **公開**: 自分の生物 (好きな世代) を「ひとこと」を添えて出す
- **記録**: 「平地12秒」の記録で並ぶ。記録は見る人の端末で走らせ直して測るので、ごまかしようがない
- **一緒に走る**: 気に入った生物をかけっこに呼んで、自分の生物と並べて走らせる
- 👏 拍手

データは softevo7 / 8 と同じ Firebase Realtime Database の `softevo9/v1/` の下に置きます (softevo8 のデータとは混ざりません)。
Firebase コンソール → Realtime Database → ルール に次の1行を追加してください:

```json
{
  "rules": {
    "leaderboard": { ".read": true, ".write": true },
    "softevo9": { ".read": true, ".write": true }
  }
}
```

だれでも書き込めるデータなので、受け取った生物は体・脳の大きさ・文字数などを検証してから使います。

## 物理エンジンについて

- Verlet 積分。**骨**は剛体拘束、**筋肉**はバネ（中心力）として実装。
  位置拘束で筋肉を解くと、骨と筋肉がせめぎ合った時に角運動量が湧き出す「数値的な永久機関」が生まれ、
  生物が宙を回転して秒速 8m で飛んでいく不正解が進化してしまうため。
- 筋肉は瞬時には動けない（ローパス）ので、振動の悪用が起きにくく動きも有機的。
- 結果として、二足は直立して左右の足を交互に接地する歩行、四足はトロット状の歩容に自然に進化する。

## 脳の入力

| グループ | 内容 |
|---|---|
| 筋の伸び | 各筋肉の現在長 / 静止長（固有感覚） |
| 接地 | 各ノードが地面に触れているか（足裏の感覚） |
| 姿勢/速度 | 体全体の傾き (sin, cos)、重心の速度 (→, ↑) |
| リズム | 脳内の振り子 (sin, cos)。周期は遺伝子で進化する |

出力は筋肉ごとに 1 ニューロン（tanh）。隠れ層は 1〜2 層で大きさは設計画面で変更可能。
