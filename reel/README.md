# Softevo Reels — 縦動画の枠組み (英語のみ・音ハメつき)

Softevo の生き物が「ゴールの旗に届くまで」を、Instagram のリール用の縦動画 (1080×1920 / 30fps / **16秒**) にする仕組みです。
**動画の中の文字はすべて英語**。曲と効果音もここで作ります (オリジナルのチップチューンなので著作権の心配がありません)。ナレーションは入れません (言葉は画面の文字と投稿文で)。

```
reel/
├─ make-episode.mjs   エピソードをつくる (体のオーディション → 進化 → ゴールと見せる世代を選ぶ → 台本・投稿文)
├─ music.mjs          曲と効果音 (120 BPM・8小節 = 16秒。台本のコマに合わせて鳴らす)
├─ index.html         再生ページ (プレビュー・音つき再生・安全領域・表紙)
├─ reel.js            1コマを描く (Softevo のドット描画をそのまま使う。決定論なので何度描いても同じ画)
├─ capture.mjs        全コマを PNG に → 曲を作る → MP4 (1080×1920 H.264、音量 -14 LUFS) + 表紙・投稿文
└─ episodes/epNNN.json
```

## つくり方

```bash
# 0. 初回だけ
npm i -D playwright && npx playwright install chromium      # MP4 にするには ffmpeg も

# 1. エピソードをつくる (24体をオーディション → 上位4体を 300 世代 → 台本にいちばん合う体)
node reel/make-episode.mjs --ep 2
#    同じ体で作り直すとき (表示される「体の種」を使う)
node reel/make-episode.mjs --ep 1 --body-seed 230732 --goal 10

# 2. 確認する (音つき)
python3 -m http.server 8000
#    → http://localhost:8000/reel/?ep=episodes/ep002.json&audio=../out/ep002/music.wav&guides

# 3. 書き出す → out/ep002/ に ep002.mp4 / cover.png / caption.txt / music.wav / frame_*.png
node reel/capture.mjs reel/episodes/ep002.json
```

`make-episode.mjs` のオプション

| オプション | 中身 |
|---|---|
| `--seed N` `--cast 24` `--cast-gens 30` `--finalists 4` `--gens 300` | オーディション (同じ種なら同じ回) |
| `--body-seed N` | 体を決めて作る |
| `--goal 10` | ゴールの距離 (m)。省略時は「いちばん惜しくなる距離」を自動で |
| `--hook compare / fail / preview` | 最初の1秒 (下の「つかみの3通り」) |
| `--color purple` | 生物の色 (red orange lime teal blue purple pink)。節点の輪と番号の色。省略時は番号で順番に |
| `--name BOB` | この生物の名前 (コメントで決まったら。見出しと表紙に出る) |
| `--prev BOB` | 前の回の生物に決まった名前。この回の 0:02〜0:04 に `#001 is now BOB` と発表 |

## 台本「drop16」 (16秒 = 120 BPM × 8小節。1拍 = 15コマ)

| 小節 | 時間 | 場面 | 画面 | 音 |
|---|---|---|---|---|
| 1 | 0:00 | **つかみ** (3通り) | 例 compare: 上に `GEN 0`、下に `GEN 57`、まん中に `↓ 57 generations later ↓` → 1秒で本編へ `CAN'T EVEN STAND` | 1コマ目から鳴る。倒れて頭を打つ瞬間 = 拍の頭に「ボコッ」 |
| 2 | 0:02 | 成長 (2つの世代) | `GEN 4` → `GEN 9` (拍の頭でカット) | カットごとに「ピッ」 |
| 3 | 0:04 | **惜しい!** 旗の数cm手前で時間切れ | 旗とのすき間に寄る / `SO CLOSE...` `7 cm short` | 3拍目で全部止まって「ワワワワ〜ン」 |
| 4 | 0:06 | 最後の挑戦 | 4拍目はスロー + 画面の端が暗くなる | スネアの連打 + ライザー → **4拍目は無音** |
| 5 | 0:08 | **ゴール** = ドロップ | ゴール直後の着地で 白く光る・揺れ・紙吹雪 / `GOAL!` | 全部が鳴る (効果音は小さなアクセントだけ) |
| 6 | 0:10 | 勝利の走り | `nobody taught it how` | 1歩 = 1拍 (着地がキックと同時) |
| 7 | 0:12 | 結果 (世界と脳の所をまるごと結果の画面に) | `GEN 0 → GEN 57` / `0.3 m → 17.8 m` / `2,784 tries` | 数字が増えると「チチチ…チーン」 |
| 8 | 0:14 | 呼びかけ + 巻き戻し | `FOLLOW for the next creature` / `Name it ↓` | 巻き戻しの音 → フィルで 1小節目へ |

**画面の決まり**
- 1コマ目は「見出し + 進み具合のバー + 世代」(compare は「見出し + 上下の窓 + 1行」) だけ。脳は 1秒目から出る
- 文字は安全域 (上14%・下35%・左右6%) の中。世界と脳は下の方 (画面の約88%) まで大きく使う。脳は右のボタンの列にかからない幅
- 上のバーで「いまの距離 → 旗」が常に分かる (白い目盛 = それまでの最高記録)
- 歩き方が規則正しければ、ゴール直後の着地をドロップに、勝利の走りを 1拍 = 1歩 の速さに (`stride`)
- 最後のコマは巻き戻して最初の姿・画角・脳 (第0世代の重み) に戻る

**台本の選び方 (自動)**
- 距離は「鼻先」(いちばん前の節点) で測る → 旗に触れた見た目と数字が一致する
- ゴールは 5〜30 m から、「ゴールのすぐ手前で止まった世代」がいちばん惜しくなる距離 (最終世代は 3〜9 秒で到達)
- 第0世代は 48 体のランダムな脳から、0.3〜1.2 秒で倒れる個体 (いなければ動けない個体)

## つかみの3通りと A/B

| `--hook` | 最初の1秒 | ねらい |
|---|---|---|
| `compare` (標準) | 上に第0世代 (倒れる)、下に最終世代 (進む)、まん中に1行 | 失敗と成功の対比そのものがつかみ |
| `fail` | 第0世代が倒れるだけ | 笑いで止める |
| `preview` | 最終世代が進む姿を1秒 → 第0世代へ | 成功の先出し |

**1回の投稿で変えるのは1つまで** (つかみを変えたら、ほかは同じ台本のまま)。投稿ごとに Instagram のインサイトで
「2秒時点で残った割合」「最後まで見た割合 (目安 75%)」「リプレイ (ループ)」「コメント数」を記録して、つかみだけを磨く。

## 手で直す
`episodes/epNNN.json` の `texts` (画面の文字) / `caption` / `hashtags` / `cover` / `creature` を書き換えて、もう一度 `capture.mjs` を回すだけ。ゲノムは JSON に入っているので同じ動きが必ず再現されます (進化のやり直しは不要)。

## 投稿のしかた
1. `epNNN.mp4` (1080×1920・H.264) を**そのまま**リールとして投稿。動画をほかのアプリに添付したり送り直したりすると 720p などに作り直されることがある
   - 確かめ方: iPhone の写真アプリで動画を開いて (i) → `1080×1920` と出れば元のまま (`SPEC.txt` に仕様と sha256)
   - 人に渡す・評価に出すときは `epNNN_1080x1920.zip` (ZIP の中の動画は変換されない)
   - Instagram は「設定 → メディアの画質 → 最高画質でアップロード」をオンに
2. Instagram の音源は**付けない** (曲と動きがずれる)
3. 表紙は `cover.png` (プロフィールの一覧で 4:5 / 3:4 に切り取られても大事な所が残る)
4. 投稿文は `caption.txt` (英語・最後に「👇 Name this creature」・ハッシュタグは 6 個)
5. コメントで決まった名前は、次の回で `--prev NAME` (発表)。その生物を出し直すときは `--name NAME`
6. 同じファイルを YouTube Shorts にも (このジャンルの中心は YouTube)

## シリーズの型

**プロフィール (bio) の例**
> Random bodies. Random brains. They learn to move by evolution alone — a new pixel creature every episode.

| 企画 | 中身 | 枠組みでの作り方 |
|---|---|---|
| Creature #NNN (毎回ちがう生き物) | 本編 | `--ep N` で毎回 |
| You name it | 前の回のコメントで決まった名前を発表 | `--prev NAME` |
| You design it | コメントで集めた体 (「脚5本」「しっぽ2本」) | アプリで体を作って書き出し → JSON の `blueprint` を差し替えて進化からやり直す |
| 番号つきの課題 | 階段 (STAIRS)・氷 (ICE)・低重力 | (次の段階: 地形と重力を台本で選べるように) |
| Race day / パレード | 過去回どうしのかけっこ、全世代パレード | (次の段階) |

タイトル「AI LEARNS TO WALK」は分かりやすい反面、同じ名前の有名な動画があります。シリーズが育ったら、見出しの後ろや表紙で Softevo らしさ (脳の動き・名前の募集) を前に出していく。
